# Minifilter 内核驱动 PoC 测试计划（Hyper-V 虚拟机）

> 目的：评估开源/研究级 minifilter 驱动能否为 CipherBox 提供"**卷内明文按进程管控**"的补充层
> （授权进程=LO/WPS 可读写 `S:\`，非授权进程=微信/浏览器等 拒绝访问）。
> 被测对象：FOKS-TROT（预编译优先）、Hades-Windows（目录访问黑白名单）、EaseFilter demo（可选）。
> 测试环境：**Hyper-V 虚拟机**（与主机隔离；被测驱动均为研究/实验性质，蓝屏风险由快照兜底）。
> 仓库已克隆至 `C:\minifilter-poc\`（Hades-Windows / FOKS-TROT / FilterDriver）。

## 1. 虚拟机准备

| 项 | 规格 |
|---|---|
| 虚拟化 | Hyper-V（主机已启用，vmms 服务运行中 ✓） |
| VM | Gen2、2 vCPU、4GB 内存、60GB 动态 VHDX、名 `cipherbox-poc` |
| 客户机 | Windows 10 x64 21H2+（FOKS-TROT 已验证版本范围）；ISO 来源待定 |
| 自动化 | **PowerShell Direct**（`Invoke-Command -VMName`）：Windows 装好后，主机直连 VM 下发命令/拷文件，全程无需碰 GUI |

**装完必做**：
1. 快照 `clean-baseline`
2. 开测试签名：`bcdedit /set testsigning on` + 重启（桌面出现"测试模式"水印属预期）→ 再拍快照 `testsigning`
3. （可选，测试机）关闭 Defender 实时保护，避免干扰未签名驱动加载

## 3. 通用测试流程（每个驱动重复）

- S0 快照 `before-<driver>`
- S1 安装/加载驱动（按各自文档；加载失败即记录并终止该项目）
- S2 建测试目录 `C:\SecretDir`；放入测试文件（真实 docx + txt）；准备两类进程：**授权**（LO/notepad/wps）、**非授权**（cmd、未列名程序）
- S3 用例执行（见各驱动小节）
- S4 异常操作：强杀驱动服务进程、快速开关文件、复制粘贴风暴
- S5 卸载 → 验证文件恢复原状 → 异常则回滚快照

## 4. FOKS-TROT 用例（按进程明文/密文视图）

| # | 用例 | 步骤 | 通过判据 |
|---|---|---|---|
| F1 | 安装 | 测试签名 + Release 安装包 | 驱动服务启动，无蓝屏 |
| F2 | 授权写入→落盘密文 | 授权进程在机密目录保存 docx | 用原始字节直读 = 密文（非 `PK` 头）；授权进程读 = 明文视图 |
| F3 | 非授权读→密文视图 | `cmd /c type C:\SecretDir\x.docx` | 输出不可读密文 |
| F4 | 非授权修改→拒绝 | 非授权进程尝试写入 | 拒绝或写入被还原 |
| F5 | WPS/tmp-rename 保存流 | WPS 保存 docx（走 tmp 重命名路径） | 不死锁、密文正确（作者已适配 WPS 11.1） |
| F6 | **"另存为"缺口复现** | 授权进程另存到机密目录外 | 记录明文是否落卷外（验证作者自述的已知缺口） |
| F7 | 稳定性 | 30 分钟混合操作（打开/保存/复制/删除/强杀进程） | 无蓝屏、无卡死、驱动可控 |
| F8 | 性能 | 100MB 文件读写计时 vs 无驱动基线 | 记录开销百分比 |
| F9 | 崩溃恢复（可选） | 强杀驱动服务进程 | 记录系统状态与恢复路径 |

## 11. 已知风险与红线

- 被测驱动均为研究/实验性质：**蓝屏按预期发生，快照兜底**；每次装驱动前必拍快照

- VM 内不放任何真实业务数据；网络默认隔离（仅测试需要时装 NAT）
- RealBlindingEDR 类攻击工具**不纳入**测试（合规）
